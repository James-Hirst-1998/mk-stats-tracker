# Site content

The written pages on the site. Edit these, not the components.

- `setup.md` — Get set up
- `journey.md` — How it was built
- `updates/` — one file per update, named `YYYY-MM-DD-short-name.md`. The
  first line is `# Title`. Newest shows first, and the newest is on the front
  page.

Plain Markdown. Links to other pages are hash links: `[Stats](#/stats)`.
