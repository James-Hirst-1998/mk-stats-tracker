# This site

The stats page no longer needs to run on the machine with the races on it.
Open **Stats → Load races** and pick a night's folder. It is read in your
browser and never uploaded, and it is still there after a reload.

No races of your own? **See an example night** loads a real one: four players,
Maple Treeway and Koopa Cape.
